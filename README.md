# 오행 사주

생년월일시로 오행(목·화·토·금·수) 분포를 보여주고, 그에 따른 성격 분석과 연도별 재물·건강·연애운을 알려주는 정적 웹앱입니다.

- 천간·지지·십신 용어 없이 오행과 쉬운 문장으로만 결과를 표시
- 모든 계산은 브라우저에서 수행 (입력 정보가 서버로 전송되지 않음)
- 빌드 과정 없음: `index.html`을 정적 호스팅(GitHub Pages)으로 배포

## 계산 방식

| 항목 | 처리 |
|---|---|
| 연주·월주 | 입춘·12절의 정확한 절입 시각 기준 |
| 서머타임 | 1948~1951, 1955~1960, 1987~1988년 1시간 차감 |
| 표준자오선 | 1908~1911, 1954~1961년은 동경 127.5° 기준 |
| 진태양시 | 출생지 경도 + 균시차로 일주·시주 보정 |
| 자시 | 야자시 (23시 이후 일주는 당일 유지) |
| 시간 모름 | 시주 제외 6글자로 계산 |

연도별 운세는 해당 연도 오행이 내 오행(일간)과 맺는 관계, 일간의 강약, 오행 과다·부족, 일지와의 합·충을 규칙 기반으로 점수화(1~5)합니다.

## 구조

```
index.html          화면
css/style.css       스타일
js/saju.js          만세력 계산 (사주 → 오행)
js/interpret.js     성격·연도별 운세 해석
js/app.js           입력·렌더링·공유
vendor/lunar.js     lunar-javascript 1.7.7 (MIT, 6tail)
```

## 로컬 실행

```
python -m http.server 8000
```

## 알려진 한계

- 음력 변환은 중국 기준 음력 데이터를 사용해 일부 날짜에서 한국 음력과 하루 차이가 날 수 있음
- 서머타임 시작·종료는 날짜 단위로 처리

결과는 재미와 참고용이며 의료·법률·투자 판단의 근거가 아닙니다.
